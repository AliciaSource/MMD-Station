## 1. 安装并打开 MMD Station

### 环境要求

- Blender 4.4。
- 内置原生物理与 IK 库要求 Windows x64。
- **MMD Tools 是必需依赖。**
  - [Blender Extensions 官方页面](https://extensions.blender.org/add-ons/mmd-tools/)
  - [官方 GitHub 仓库](https://github.com/MMD-Blender/blender_mmd_tools)

### 安装步骤

1. 在 Blender 中打开 **编辑 > 首选项 > 获取扩展**。
2. 搜索 **MMD Tools**，安装并确认已经启用。
3. 通过 **编辑 > 首选项 > 插件 > 从磁盘安装** 安装 `mmd_station-X.Y.Z.zip`。
4. 启用 **MMD Station**。
5. 打开 3D 视图，按 `N`，选择 **MMD Station** 选项卡。

如果缺少 MMD Tools，PMX/VMD/VPD 导入导出和 MMD 数据访问都无法正常工作。排查 MMD Station 之前，应先确认 MMD Tools 已安装并启用。

## 2. 认识界面与选择规则

面板顶部包含：

- 模型、动作和姿态的导入导出快捷入口。
- 当前 MMD Station 版本号。
- **GitHub** 跳转按钮。
- 六个工作区：**代理创建**、**MMD 查看器**、**Morph 编辑器**、**显示枠**、**物理预览**和 **MMD IK**。

### 活动行与勾选行不是一回事

很多列表同时存在两种状态：

- 蓝色高亮行是**活动项**，下方属性区域显示它的详细设置。
- 复选框是**批量选择**，删除、排序、复制、镜像等批量操作只处理勾选项。

只有一个有效目标时，部分操作会直接应用；有多个目标时，应先明确勾选需要处理的行。

### 选择 MMD 模型

多数工作区顶部都有 **MMD 模型**。可以直接指定 MMD Root，也可以选中模型内部对象后点击刷新。如果通过 MMD Tools 或其它面板修改了模型，列表未立即变化时点击刷新即可。

## 3. 导入导出 PMX、VMD 与 VPD

面板顶部的按钮会打开对应的 MMD Tools 文件浏览器。

### 模型

- **导入**：通过 MMD Tools 导入 PMD 或 PMX。
- **导出**：导出 PMX。导出前先选中目标 MMD 模型内部对象。

同一 Blender 会话内第一次完整 PMX 导出会建立 Shadow Model。后续如果改动适合快速路径，可以加速覆盖导出；出现不安全的结构变化时会自动退回完整 MMD Tools 导出，不会为了速度跳过完整内容。插件会记住本会话上一次导出目录和文件名。

### 动作

- **导入**：通过 MMD Tools 导入 VMD，导入的 Morph 动画会自动连接到 MMD Station 中央 Morph 滑块。
- **导出**：导出 VMD。MMD Station 会临时准备 MMD Tools 能识别的动画结构，导出结束后恢复 Blender 原状态。

### 姿态

- **导入**：导入 VPD 姿态。
- **导出**：把当前姿态导出为 VPD，并在当前 Blender 会话中记住上一次保存位置。

## 4. 创建与编辑表面代理

表面代理是一种可编辑 Mesh 控制面，用来为裙子、头发、丝带、袖子等结构生成规则骨链、权重、刚体和 Joint。

### 4.1 从选区创建代理

1. 选择模型 Mesh，进入**编辑模式**。
2. 选中需要生成代理的表面顶点。
3. 打开 **代理创建 > 基本 > 代理创建**。
4. 选择拓扑：
   - **闭合**：裙子一类环状结构。
   - **打开**：头发、丝带一类片状结构。
5. 设置圆周方向列数与最大高度层数。
6. 输入不会与其它代理冲突的名称前缀。
7. 可选：指定目标骨架和连接骨骼。
8. 如果需要给原 Mesh 写入生成骨链的权重，保持**生成并规格化权重**启用。
9. 点击**从选区创建裙面代理**。

闭合代理至少需要三列。单列代理会生成可雕刻控制带，但物理仍是一列；雕刻时应关闭 Dynamic Topology。

当前缀以可识别的左/右标记开头时，插件会在同一个 Mesh 中建立双侧镜像布局。根据选区条件，可以使用精确镜像或两侧独立拟合。

### 4.2 代理参数

- **径向偏移**：让拟合后的代理远离或靠近原表面。
- **目标骨架**：指定代理骨骼建立在哪个 Armature 中。
- **连接骨骼**：把各列顶部连接到已有模型骨骼。
- **离开编辑/雕刻后自动同步**：代理形状变化后自动更新骨骼端点。

### 4.3 编辑或恢复代理

**代理编辑**区域包含：

- **同步骨骼到代理**：按当前代理顶点移动骨骼端点，不改骨骼名称、层级和权重。
- **根据代理重算权重**：只重算原本已受该代理骨链影响的顶点，并保留锁定变形权重。
- **识别或恢复所选代理**：对象安全改名或重新关联后恢复代理身份数据。

也可以从现有骨链恢复代理：

1. 在 **MMD 查看器 > 骨骼** 中勾选一条或多条连续代理骨链。
2. 选择打开或闭合；打开模式可以决定是否连接左右两侧。
3. 点击**从勾选骨骼恢复或新建代理**。

普通名称、`.L/.R` 与 `_L/_R` 骨链均受支持。

## 5. 生成代理物理

**代理创建**下半部分会根据当前代理生成 MMD 刚体和 Joint。

### 5.1 基本流程

1. 选择 **MMD Root** 与**物理代理**。
2. 在**基本**、**刚体**、**纵 Joint**、**横 Joint**页检查参数。
3. 可点击**填入：稳定中长裙**或选择自定义预设。预设只会填入面板，不会立即修改已有物理。
4. 新建物理时点击**生成 MMD 刚体和 Joint**。
5. 修改参数后点击**应用参数到当前代理**。

### 5.2 刚体设置

- 选择球体、盒体或胶囊。
- 分别设置顶层与下层刚体类型。
- 尺寸值为 `0` 时自动按代理单元拟合；非零值按骨长比例覆盖。
- 起始值、末端值和补间可以让尺寸、质量、阻尼、弹性、摩擦沿骨链渐变。
- 设置碰撞组和不碰撞组。裙链不应互相碰撞时可使用**屏蔽同组碰撞**。

### 5.3 Joint 设置

纵 Joint 连接每列上下刚体，横 Joint 连接相邻列。可以设置：

- 移动与旋转上下限。
- 移动与旋转弹簧。
- 从顶部到底部的参数补间。
- 是否生成横向 Joint。

应用保护复选框决定**应用参数**时哪些已有数据允许被覆盖。

### 5.4 编辑代理后的同步

- **同步当前代理刚体和 Joint**只更新位置和旋转。
- **骨骼变动后自动同步**自动执行相同的位置维护。
- 同步不会修改形状、类型、尺寸、物理参数或碰撞设置。

## 6. 使用 MMD 查看器

查看器包含材质、骨骼、刚体、Joint、诊断五页。大型模型可以使用搜索、名称前缀与**仅显示当前代理**缩小范围，吸管按钮可以从活动项提取前缀。

通用列表操作：

- **全选**、**全不选**、**反选**、**区间选组**。
- 顶部、上移、下移、底部、活动项之前、活动项之后等按钮会在支持的列表中调整真实 PMX 顺序。
- **将勾选项选入 Blender**：列表选择同步到 3D 视图。
- **从 3D 视图同步选中项目**：执行反向同步。

### 6.1 材质

材质表格显示 PMX 序号、Blender 材质名、MMD 名称与 MMD 英文名。

- 排序勾选材质，控制导出 PMX 的材质顺序。
- 同步材质名称，校对 Material ID 与单材质物体编号前缀。
- 按材质拆分活动多材质 Mesh；使用兼容 MMD Tools 的拆分逻辑，保留法线并清理接近零的 ShapeKey。
- 展开 **MMD 纹理**：添加/移除主纹理和球体纹理，设置球体纹理模式以及共享/自定义 Toon 纹理。
- 展开 **MMD 材质**：编辑 ID、名称、注释、漫射/Alpha、高光、环境色、阴影开关、描边颜色与描边大小。
- 字段右侧的复制按钮会把该字段复制到所有勾选材质。

### 6.2 骨骼

骨骼列表可以读取 3D 视图中 Edit/Pose Mode 的已选骨骼。活动骨骼属性区可以编辑：

- Bone ID、MMD 日文名/英文名、是否变形。
- 变换顺序与物理后变换。
- 可操作、末端标记和 IK 旋转限制。
- 固定轴、局部轴。
- 附加旋转/移动的目标与影响。
- 骨骼末端连接方式。

其它工具：

- **AI翻译勾选骨骼日文名**使用共享 AI 设置。
- **补全勾选/全部**补全 MMD 名称并统一镜像后缀。
- 把骨骼名称同步到绑定刚体或 Joint。
- **骨骼细分**按曲率重采样勾选骨链，连续生成 ID，并把原顶点组权重分配到新分段。
- **从选中骨骼创建 MMD 物理**可以生成追踪刚体、物理刚体、父子 Joint，或同时生成刚体和连接 Joint。
- **批量清理骨骼**会先把权重归并到指定目标骨骼，再删除勾选骨骼及其绑定刚体/Joint。

### 6.3 刚体

活动属性区可以编辑名称、绑定骨骼、类型、形状、尺寸、碰撞组、质量、摩擦、弹性与阻尼。

批量工具可以：

- 删除勾选刚体及相关 Joint。
- 从两个勾选刚体创建 Joint。活动行为刚体 B，另一个勾选行为 A。
- 创建镜像刚体，或把勾选源项参数同步到已有镜像刚体。
- 把勾选刚体的当前轴向同步到以其为 B 端点的 Joint。

### 6.4 Joint

活动属性区可以编辑名称、刚体 A/B、XYZ 移动/旋转限制和弹簧。

- 删除勾选 Joint。
- 创建或同步镜像 Joint。
- 从刚体 B 同步名称。纵向/锚点 Joint 直接使用刚体名，横向 Joint 追加 `_H`。

### 6.5 诊断

诊断只报告能够确认的模型结构问题，不评价创作性的物理参数。

1. 选择一行查看问题与处理建议。
2. 点击箭头跳转到受影响对象或数据。
3. 点击工具按钮尝试确定性的安全修复。
4. **一键修复**只执行结果唯一可靠的修复，需要人工判断的项目会跳过。

## 7. 编辑 Morph

选择 MMD 模型后，可以切换材质、UV、骨骼、顶点、群组五类 Morph。列表中央的数值滑块可以直接预览 Morph，也支持插入动画 Keyframe。

### 7.1 列表操作

- 显示/隐藏日文名、英文名，并用搜索过滤。
- 新增、删除、清理空 Morph，重新排序勾选项。
- **区间选组**会勾选当前可见列表中首尾两个勾选项之间的全部项目。
- **日文名同步到英文名**只复制名称，不进行翻译。
- **AI翻译**翻译勾选 Morph 的日文名或中文名。

### 7.2 AI 翻译设置

点击齿轮并填写：

- API 基础地址；插件会自动追加 `/v1/chat/completions`。
- API Key。
- 服务实际支持的模型名称。

配置保存在 Blender 插件首选项中。导出前应检查 AI 生成的名称，尤其是符号和左右命名。

### 7.3 复制与粘贴

**复制勾选 Morph**会把 PMX Editor 兼容 CSV 写入剪贴板；**从剪贴板粘贴 Morph**读取相同格式。

Bone、Material、Group Morph 可以在兼容模型之间复制。Vertex Morph 与顶点组型 UV Morph 依赖模型拓扑，跨模型无法安全复制时会主动跳过。

### 7.4 各类详情编辑

- **Material Morph**：新增/删除/排序材质详情；批量勾选详情行；应用隐藏/显示预设；编辑乘算/加算、漫射、描边、高光、纹理、球体纹理和 Toon 参数。
- **UV Morph**：选择 UV～UV4，管理受影响 Mesh/顶点组，查看或清除 UV 预览。
- **Bone Morph**：编辑目标骨骼的移动、旋转和权重。带权重的 Bone Morph 只能在实际受该骨骼及子孙骨骼影响的 Mesh 上转换为 Vertex Morph。
- **Vertex Morph**：选择并跳转到目标 Mesh/ShapeKey。清理时使用界面显示的局部坐标位移阈值。
- **Group Morph**：把其它 Tab 勾选的 Morph 加入当前群组，并编辑每个成员权重。

VMD 导入导出已与中央滑块连接。在滑块上按 `I` 添加的 Keyframe 可以继续在 Blender 动画工具中查看和编辑。

## 8. 编辑显示枠

显示枠决定 PMX/MMD 菜单中的项目分组。

1. 选择 MMD 模型。
2. 上方列表用于新增、删除、选择和排序显示枠。
3. 下方列表用于新增、删除、选择和排序当前显示枠中的项目。

普通显示枠：先在 Edit/Pose Mode 选择骨骼，再点击**添加所选内容**。**智能补充未收录的可见骨骼**会加入尚未出现在任何显示枠中的可见骨骼。

**表情**显示枠：先在 Morph 编辑器勾选 Morph，再添加。**智能重排序表情枠**按群组、材质、UV、骨骼、顶点排列有效且非空的 Morph。

其它工具：

- 对显示枠或显示项执行区间选组。
- 清理目标骨骼/Morph 已不存在的失效项。
- 把勾选显示骨骼同步选入 Blender。
- 在列表下方编辑活动显示枠或活动显示项详情。

## 9. 预览物理

MMD Station 使用内置原生求解器，不会创建 Blender Rigid Body World。

### 9.1 选择范围

- **当前代理**：只预览所选模型中的当前代理。
- **整个模型**：预览所有勾选 MMD 模型。通常每个模型使用自己的交互编号，彼此独立运行。

求解尺度和交互编号相同的模型会共享碰撞 world。只有多个模型确实需要互相碰撞时才应这样设置。

### 9.2 求解设置

- **求解尺度**通常会根据导入模型自动识别。只有识别错误时才手动覆盖；强制更改会改变 MMD 空间尺寸。
- 可以选择 **MMD 本体**或 **PMX Editor** DLL 目标。
- 设置固定频率、子步数、重力和是否显示刚体运动。
- **更新刚体 / Joint 到当前姿态**会从 Rest Pose 变换物理对象到当前 Action 姿态，同时保留原始偏移。

### 9.3 启动、重置与停止

- 启动当前代理或所有勾选模型。
- **重置**恢复启动快照，但保持预览继续运行。
- **停止**恢复原姿态并结束对应会话。

模型被移动、Action 改变或物理结构被编辑后，应重置或重新启动预览，让求解器取得干净快照。

## 10. 烘焙与修复物理动画

物理烘焙会生成独立的 `<源 Action> · Physics Bake` Action，不覆盖源 Action。

### 10.1 烘焙区间

1. 选择 MMD Root 和源 Action。
2. 设置起始、结束、预热。
3. 选择**独立烘焙**或**续接上一段**。
4. 选择：
   - **快速烘焙**：分时间片求解，不进行实时播放。
   - **播放烘焙**：按场景播放速度逐帧显示求解结果。
5. 查看当前帧、速度和预计剩余时间。按 `Esc` 或鼠标右键取消。

取消会恢复原 Action、时间帧和启动姿态，不会提交半成品区间。

已完成区间会显示范围、衔接方式、烘焙模式和速度。点击单行 `X` 删除一个区间，点击**清空**删除当前 Action 的全部烘焙结果。

物理快照保存在 `.blend` 旁边；未保存工程第一次保存时会自动迁移。如果快照文件丢失，需要重新烘焙对应区间。

### 10.2 修复已烘焙区间

1. 切换到生成的 Physics Bake Action。
2. 在已完成区间内部设置修复起止帧。
3. 在任意中间帧进入 Pose Mode，调整一根或多根动态物理骨骼。
4. 点击**记录当前帧修正**，可以记录多个中间锚点。
5. 点击**重新解算并衔接**。

修复层会自动保持首尾为零修正，并平滑结合中间记录的修正帧。垃圾桶按钮用于清除当前修复引导。

## 11. 启用 MMD 兼容 IK

**MMD IK**会保持原 MMD Tools Armature 为唯一可见、唯一绑定骨架，同时在内存中接管兼容的 MMD IK 链。

1. 选择 MMD 模型。
2. 点击**启用 MMD IK 兼容**。
3. 正常播放、拖动时间轴，并继续在原 Armature 上制作 Keyframe。
4. 点击**关闭 MMD IK 兼容**，停止原生接管并恢复 Blender/MMD Tools 求值。

该运行时不会添加导出骨骼，也不会修改 PMX 骨架。模型对象发生变化后，应刷新或重新启用运行时。

## 12. 自动更新与界面语言

### 自动更新

更新设置位于 **编辑 > 首选项 > 插件 > MMD Station**。

- 默认只检查稳定的 GitHub Releases。
- pre-release 需要用户主动开启。
- **立即更新**会下载对应 GitHub Release 附带的 ZIP，保留一份回滚备份，替换完成后需要重启 Blender。
- `main` 分支的普通开发 commit 永远不会作为更新提供。

### 界面语言

MMD Station 自动跟随 Blender 界面语言：

- 简体中文和繁体中文使用中文 UI。
- 其它任何 Blender locale 使用英文 UI。

在 **编辑 > 首选项 > 界面 > 翻译 > 语言**中修改。

## 13. 常用完整流程

### 从 Mesh 制作裙子物理

1. 在 Edit Mode 选择裙子顶点。
2. 使用足够的列数和高度层数创建闭合代理。
3. 检查或雕刻代理，离开 Edit/Sculpt Mode 后同步骨骼。
4. 填入稳定中长裙预设。
5. 生成刚体和 Joint。
6. 运行诊断，再启动物理预览。
7. 调整参数、应用参数、重置预览并重新比较。
8. 实时预览满意后再烘焙。

### 从现有骨链制作物理

1. 在 MMD 查看器 > 骨骼中，从 3D 视图同步已选 Pose/Edit 骨骼。
2. 使用**从选中骨骼创建 MMD 物理**生成追踪刚体、物理刚体、Joint 或组合结果。
3. 在刚体与 Joint 页检查生成内容。
4. 预览并调整。

### 导出前检查模型

1. 运行诊断并处理可确认的结构错误。
2. 检查材质顺序、名称、ID 和纹理路径。
3. 检查骨骼名称与 PMX 顺序。
4. 清理空 Morph，检查表情显示枠。
5. 从顶部快捷入口导出 PMX，并在目标 MMD 软件中检查结果。

## 14. 常见问题

### 找不到 MMD Station 选项卡

- 确认 Blender 为 4.4。
- 确认 MMD Tools 与 MMD Station 都已启用。
- 安装或更新后重启 Blender。

### 导入导出按钮不可用或报错

- 先安装并启用 MMD Tools。
- 导出前选择目标 MMD 模型内部对象。
- 确认文件格式受当前 MMD Tools 操作支持。

### 列表中找不到目标项目

- 清空搜索与前缀过滤。
- 关闭**仅显示当前代理**。
- 选择正确 MMD Root 并点击刷新。

### 无法创建代理

- 必须在 Mesh Edit Mode 中选择顶点。
- 闭合代理至少使用三列。
- 使用唯一前缀，或明确选择恢复已有代理。

### 物理预览无法启动

- 内置 DLL 只支持 Windows x64。
- 选择有效 MMD Root 以及代理/模型范围。
- 确认刚体与 Joint 已存在且结构有效。
- 启动物理预览前先停止正在运行的烘焙。

### 中英文界面没有切换

- 修改 Blender 界面语言，而不是只修改操作系统语言。
- 确认 Blender 首选项已启用界面翻译。
- 修改已安装插件文件后重启 Blender 或 Reload Scripts。
